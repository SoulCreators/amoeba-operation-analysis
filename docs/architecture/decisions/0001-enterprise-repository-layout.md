# ADR-0001：保留六模块，统一入口与工程治理

- 日期：2026-10-21
- 状态：本地已实施，待团队代码评审
- 基线：`c8ddc820c2806f886edadbaa06619cfc5cd879fb`

## 背景

已有 API/Worker 和四个内层模块具备明确方向，但旧骨架共存，前端以 AppFinal 命名承担全部页面，文档中存在失效绝对路径和过时状态。直接迁入 apps/packages 或拆分微服务会增加 Maven、Docker、CI 和 Spring 接线变更，不能解决财务计算的版本与权限问题。

## 决策

保留 backend/frontend/database/deploy 根目录和 Maven 模块坐标。统一主入口，删除未被当前入口引用的六个 Java 骨架类；Worker 的 amoeba 包保留。前端按 app 入口、features 工作台、shared API 职责划分；测试归入 tests/unit，E2E 保留既有路径。项目治理、需求与历史资料归入 docs，对外入口更新到 README。

通过 Node 标准库检查模块依赖、Java import、启动类、前端 shared 边界和迁移编号，接入 CI。构建脚本默认执行已有测试。数据库迁移和财务公式不随目录调整变更。

## 影响与后续

已有前端测试仅更新目标路径和组件名称；API URL、导出协议、状态机、计算规则及依赖锁文件保持不变。路径消费者需要同步迁移，清单见评审报告。大型工作台和横向 Java 包仍需后续拆分；本轮建立可执行边界，不把新目录名称视为完整领域重构。

回滚需整体还原路径和引用后重新构建。无数据库回滚动作。删除的骨架保留于 Git 基线，不另复制到生产源码或第二套可执行目录。
