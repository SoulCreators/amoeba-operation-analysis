# 经营分析平台：本地真实联调数据与初始化配置准备清单

## 1. 本次本地测试口径

- 测试期间：先用 `2026-08`，后续替换为真实月度批次。
- 测试视角：先完成 `BASE` 基地视角，再补 `BUSINESS_UNIT` 事业部视角和 `PRODUCT_LINE` 产品线视角。
- 金额口径：统一使用不含税金额；币种、汇率和期间必须明确。
- 测试数据可以先脱敏，但维度、字段、正负号和实际业务口径不能改变。
- 本地 `local` Profile 使用内存仓储，重启服务后批次和导入任务会清空；正式留存和多人联调要切换 PostgreSQL `db` Profile。

## 2. 先准备的最小可计算数据

基地视角要让以下 5 个必需数据集在同一批次下全部通过校验：

| 数据集 | 必填字段 | 计算用途 |
| --- | --- | --- |
| `BASE_ACT_INC_COST` 基地实际收入成本 | 期间、收入计算基地、电芯型号、财经修正项目、客户简称、营业收入、销售成本 | ACT 收入、销量、销售成本、毛利 |
| `BASE_BUD_INC_COST` 基地年度预算收入成本 | 期间、收入计算基地、电芯型号、财经修正项目、客户简称、营业收入、销售成本 | BGT 收入、销量、销售成本、毛利 |
| `BASE_IDLE` 基地闲置费用 | 期间、收入计算基地、金额 | 闲置费用 |
| `BASE_L3_EXP` 基地三级费用 | 期间、收入计算基地、费用分类、金额 | 基地费用 |
| `BASE_LAB_MFG_EXP` 实验室与制造体系费用 | 期间、收入计算基地、费用分类、金额 | 基地费用 |

收入成本明细建议同时提供以下字段，便于 PVM、单位效率和矩阵计算：

- 销量/电量、拉线/线体、产出 `Wh`；
- 材料成本、直接人工、外协加工成本、制造成本-变动、制造成本-固定；
- 出货基地、产品线、事业部、客户项目、产品型号等原始维度。

每个数据集至少准备 2 个基地、2 个产品/型号、2 条明细，且 ACT 与 BGT 能按相同维度勾稽。不要只提供汇总行，否则无法验证下钻和交叉矩阵。

## 3. 为 V1.3 功能补充的数据

### 3.1 基地 × 产品矩阵

要验证正式矩阵，必须提供事业部视角的实际/预算收入成本明细，并确保每行都有：基地编码、产品编码/型号、事业部、客户项目、收入、销售成本。研发、运营、减值等没有产品归属的费用不要硬塞进产品矩阵，应作为矩阵外的桥接项保留。

### 3.2 线体单位制造费用（元/Wh）

每条线体至少提供：基地、线体、实际/预算产出 Wh、实际/预算变动制造费用、实际/预算固定制造费用。任何一行缺线体或 Wh 都会被标记为待定义，不能发布正式单位成本。

### 3.3 FC 滚动预测

需要一套正式 FC 版本元数据和快照：版本号、适用视角、基准期间、覆盖起止期间、状态、是否正式采用、发布人/时间；快照至少包含期间、范围编码、指标编码、指标值。版本号不能用 BGT 或历史 ACT 自动替代。

### 3.4 风险提示

请预算组确认收入、毛利、净利润等指标的红黄阈值、绝对 GAP 与百分比 GAP 的触发关系，以及风险责任部门和处理时限。未确认前系统只能输出“观察项”，不会冒充正式预警。

## 4. 初始化基础配置

按模板目录中的 21—29 号文件收集；第一轮最少完成前 7 类，才能验证映射和指标口径：

1. 销售项目映射：客户、原始项目、修正项目、产品线、事业部、有效标识。
2. 库存档案映射：物料、型号、产品类型、产品线、事业部、分摊比例。
3. 费用分类映射：三级费用编码/名称、费用分类、基地、产品线、事业部。
4. 费用分摊配置：期间、费用项目、来源基地、目标基地、分摊比例、有效标识。
5. 汇率配置：期间、基地、币种、汇率、换算方向、有效标识。
6. 基地分析粒度配置：基地、型号、分析粒度、有效标识。
7. 指标库配置：指标编码、名称、公式、适用视角、单位、展示顺序、启用状态、AI 摘要模板。
8. 用户权限配置：工号、角色、视角、可查看范围、明细/导出/配置权限。至少准备一个总部财经管理员和一个基地用户。
9. 非财经指标数据：期间、基地、拉线、型号、指标类别、目标/实际、指标值、来源行标识。

## 5. 提交前检查

- 所有文件第一行是唯一字段标题，期间统一为 `YYYY-MM`。
- 金额字段全部是可计算数字；负数、冲销和减值不要用文字表达。
- ACT/BGT/FC 的基地、产品、项目编码来自同一套主数据；映射不到的记录单独列出，不要直接删除。
- 同一批次同一数据集只提交一个最终文件；修订要保留版本号和修改说明。
- 先导入并校验，再查看批次完整性；5 个必需数据集通过后才能把批次移动到 `READY_FOR_CALCULATION`。

## 6. 验收时应能看到的结果

1. 批次完整性：必需数据集全部 `VALID`，问题数为 0。
2. 计算结果：ACT、BGT、绝对 GAP、GAP% 可回溯到明细维度。
3. PVM：销量、价格、材料、人工、外协、变动/固定制造费用因子有数值或明确阻断原因。
4. 基地 × 产品矩阵：能按基地、产品、项目下钻，且不把无产品归属费用混入矩阵。
5. 单位效率：每条线体能计算元/Wh；缺字段时显示阻断原因而不是返回假数。
6. 风险和 FC：没有正式阈值或 FC 版本时，页面显示待确认项，不把演示值当正式结果。
