# 指标树接口

## 查询指标树

`GET /api/v1/metric-tree/{batchNo}`

请求必须经过公司统一认证。服务端从认证主体读取工号，不接受前端传入的 `userId` 作为权限依据。

返回每个授权范围、每个启用指标库指标的：

- `scopeCode`：结果范围，如基地、产品线或事业部编码；
- `metricCode`、`metricName`、`unit`：指标定义；
- `actualValue`、`budgetValue`、`gapValue`：实际、预算及实际减预算；
- `aiSummary`：指标库维护的 AI 简析模板，供前端或 AI 服务继续生成说明。

一期公式支持指标编码、`SUM()`、加法、减法、除法和除零保护。公式按指标库配置执行，预算值通过同一表达式自动映射到 `BUDGET_` 前缀字段。未配置或无法识别的字段按零值处理，正式生产版需在数据质量校验阶段拦截并提示财经修正指标配置。

## 权限与状态

- 结果按计算结果服务的认证主体和视角范围过滤；没有授权范围时拒绝返回。
- 未发布结果仅对总部财经/管理员等具备复核权限的角色可见；已发布结果按授权范围可见。
- 指标树只读取已启用指标，不提供前端绕过权限的范围参数。
