# 批次导入与完整性接口

## 1. 批次完整性

`GET /api/v1/batches/{batchNo}/readiness`

请求必须经过认证。返回当前批次视角下的数据集目录、是否必需、任务是否存在、任务状态、问题数及 `readyForCalculation`。

```json
{
  "code": "OK",
  "data": {
    "batchNo": "BATCH-202608-BASE-001",
    "perspective": "BASE",
    "readyForCalculation": false,
    "datasets": [
      {
        "datasetCode": "BASE_ACT_INC_COST",
        "datasetName": "基地实际收入成本明细",
        "required": true,
        "present": true,
        "status": "VALID",
        "issueCount": 0,
        "taskNo": "IMP-..."
      }
    ]
  }
}
```

只有全部 `required=true` 的数据集同时满足 `present=true` 且 `status=VALID` 时，`readyForCalculation` 才为 `true`。非必需数据集缺失不阻断批次计算，但仍返回状态供页面提示。

## 2. 数据集目录

`GET /api/v1/datasets?perspective=BASE`

用于批次导入页加载当前视角可用数据集、必需标识和字段定义。基地与产品线/事业部的数据集目录由视角决定，不共用强制模板。

## 3. 创建批次与导入任务

```http
POST /api/v1/batches
Content-Type: application/json
X-User-Id: local-user   # 仅 local Profile 联调使用
```

```json
{
  "batchNo": "BATCH-202608-BASE-001",
  "period": "2026-08",
  "perspective": "BASE"
}
```

```http
POST /api/v1/batches/{batchNo}/imports
Content-Type: application/json
```

```json
{
  "datasetCode": "BASE_ACT_INC_COST",
  "fileName": "基地实际收入成本_202608.xlsx",
  "checksum": "sha256..."
}
```

## 4. Excel 校验

`POST /api/v1/imports/{taskNo}/validate`，使用 `multipart/form-data` 的 `file` 字段上传 Excel。校验会检查首个工作表的字段标题、重复字段、必填字段、期间格式和金额类型；结果写入导入问题仓储并更新任务状态。

校验通过且启用 `db` Profile 时，标准化事实会按“批次＋视角＋任务号”替换写入 `raw.pnl_fact`，重复校验不会重复叠加金额。

## 5. 计算前置条件

前端不得依据本地文件数量自行判断可计算。必须以 `readyForCalculation=true` 为准，并在计算接口失败时展示后端返回的状态或问题明细。
