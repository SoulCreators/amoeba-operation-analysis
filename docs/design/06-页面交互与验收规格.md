# 页面交互与验收规格

本文件把 V1.3 第 5.3、14、16、17 章的菜单、页面和交互要求收敛成前后端可共同验收的页面契约。它补充 [功能详细设计](01-功能详细设计.md)，不替代真实 Excel 样表、OpenAPI 和财经签字口径。标注“待确认”的内容在产品原型中需显式展示，不得使用演示数字代替。

## 1. 全局页面框架

所有页面在服务端确认用户和可访问范围后再加载数据。导航菜单可以按权限隐藏，但接口仍须逐次授权。页面跳转携带期间、视角、范围、场景、口径和结果版本；返回或刷新时仅重用仍然有效的筛选上下文。

| 固定信息 | 展示规则 |
|---|---|
| 页面身份 | 当前一级模块、页面名称、数据视角；分析结果页显示基地/产品线/事业部之一 |
| 查询上下文 | 期间、授权范围、当期/累计、ACT/BGT/GAP/FC 场景和结果版本；基地结果补充本版本粒度模式 |
| 版本状态 | 未发布、已发布、已替代、已撤回、计算中或失败；经营角色不接收草稿数值 |
| 数值格式 | 金额按单位及精度字典格式化；计算使用未舍入值；百分比、单位值按汇总分子/分母重算 |
| 空态 | 明确区分未创建批次、未上传、无权访问、等待数据、等待口径、计算失败和本期无数据 |
| 操作反馈 | 提交后返回任务号/版本号和追踪号；失败显示稳定错误码、定位及下一步，不保留旧场景数字 |

结果查询的筛选范围由服务端授权后提供。客户端传入的 `scopeIds`、页面角色、操作者和文件下载链接均不是授权凭据。被拒绝的范围不得被悄悄裁剪后当成完整结果返回。

## 2. 工作台和数据中心

| 页面 | 查询/展示字段 | 可执行操作 | 状态及验收 |
|---|---|---|---|
| 月度工作台 | 期间、视角/数据集、各数据对象必需性、有效文件版本、记录数、完整性、阻断/警告数、任务状态、责任角色、确认/发布版本 | 创建批次、进入数据清单/异常/任务/结果详情 | 没有批次时引导创建；任何数字能关联批次与版本；完成任务显示结果状态和下一步 |
| 数据清单 | 对象编码/名称、必需规则、模板编码/版本、生效文件版本、上传时间/人、校验状态、行数、控制金额 | 下载模板、上传、预检、确认替换、预览、重传 | 错模板/缺必需字段在事实生效前阻断；重传先校验后切换指针；旧版本保留 |
| 批次详情 | 批次号、期间、视角、状态、对象清单、文件版本、控制总额、完整性及最近任务 | 完整性检查、查看文件/问题、进入计算任务 | “本期无数据”须有财经声明记录；已发布批次重传需进入受控重算路径 |
| 源数据预览 | 原字段、标准字段、映射结果、分摊/归属、文件名、Sheet、行列定位、问题码 | 查询、分页、下载问题清单 | 不允许在预览直接修改原文；只返回用户获授权的行；每个标准值能回到原始来源 |

上传主流程：选期间和数据对象 → 下载当前有效模板 → 选择文件并预检 → 查看文件级及行级问题 → 修复或明确忽略可忽略警告 → 确认生效版本。解析和校验异步执行。阻断问题不能忽略，失败文件不成为有效输入；替换以整期对象版本为单位，不能部分写入后报告成功。

## 3. 异常工作台

筛选字段为期间、批次、对象、错误码、级别、处理状态和上传任务。表格至少显示级别、错误码、对象、文件/Sheet/行/列、字段、原值、标准值、原因、金额影响（适用时）、处理状态和处理人。

- **阻断**：置顶并禁止计算/确认/发布；提供下载和源行定位。只能修复源文件、映射或配置后重新校验。
- **警告**：允许有权限用户填写原因后忽略；保留忽略人、时间、原因与操作前后状态。
- **未匹配**：列出待归属对象和金额/数量影响；必需归属不能通过忽略放行。
- **已修复**：通过重传/配置更新后创建新校验任务；旧问题与旧任务保留审计，不原地改写历史结论。
- **系统错误**：显示追踪号、任务阶段、错误码和可否重试；业务校验错误不提供盲目重试按钮。

验收时对 IMP/MAP/ALL/FX/DQ/CFG/REC/SEC/SYS 错误类别至少各覆盖一条路径。处理完成后，批次完整性状态须重新读取，不得仅在前端把问题行标绿。

## 4. 配置中心

配置页面共用字段：配置类型、业务键、输出归属/规则、是否有效、维护人、修改时间、版本或并发标记、影响期间/范围。批量导入采用“文件预检 → 新增/更新/冲突/不变预览 → 确认写入”；冲突和无效行不静默覆盖。

| 配置页签 | 编辑字段与保存校验 | 影响提示 |
|---|---|---|
| 销售项目映射 | 出货基地、客户简称、客户项目改、电芯型号、产品线、事业部、巴长工号/名称；精确四键唯一，巴长归属按型号唯一 | 展示受影响产品线、事业部、巴长结果和历史发布版本 |
| 库存档案 | 物料编码、归属序号、类别/产品线/事业部等目标、分摊比例；同一物料归属比例合计 100% | 展示分配前后数量/金额和比例差；不平不得启用 |
| 费用分类 | 公司、事业部、三级部门、OU 基地、费用类别/科目、有效状态 | 失效或未命中记录不进入正式结果，显示受影响源行/金额 |
| 汇率 | 期间、收入计算基地、原币、汇率、方向、有效状态 | 国内汇率固定为 1；海外缺汇率阻断标准化；修改不重写旧版本 |
| 分摊规则 | 费用池、来源范围、接收对象、比例、指定接收对象优先标记、有效状态 | 逐级列出来源池与去向；比例合计校验和分配守恒可预览 |
| 基地分析粒度 | 基地、`BASE_MODEL` 或 `BASE_MODEL_PROJECT` | 每基地仅一个有效值；显示配置生效后会影响的未来计算和现有发布版本 |
| 指标字典 | 编码、名称、父节点、公式/受控表达式、单位、收益/成本属性、视角、顺序、状态 | 试算样例、单位/循环/除零检查；复杂 PVM/分摊不允许以自由脚本替代后端规则 |

已发布结果使用其计算时配置快照。页面必须说明配置变更何时生效及如何申请重算；不能把配置编辑直接解释为历史结果已更新。

## 5. 计算中心、确认与发布

| 页面/阶段 | 可见内容 | 操作及约束 |
|---|---|---|
| 计算任务列表 | 期间、视角/范围、批次、源版本集合、任务号、发起人/时间、状态、结果版本 | 按权限发起或重试；同一输入只允许一个有效运行任务 |
| 任务详情 | 当前阶段、已处理行数、问题数、开始/心跳/结束时间、追踪号、失败码、重试关系 | 异步刷新；失败区分可重试系统故障和需先修复的业务问题 |
| 计算报告 | 输入版本、配置/公式快照、行数与控制金额、未匹配/排除金额、分摊守恒、三视角勾稽、PVM 桥、调整和警告 | 每个差异可下钻到规则、源行和归属；任何阻断项使确认/发布禁用 |
| 结果确认 | 候选结果版本、报告摘要、差异处理、调整列表 | 财经复核并记录确认人、时间和意见；不能确认失败或阻断版本 |
| 结果发布 | 期间、视角、范围、候选版本、既有发布版本、发布范围和通知目标 | 发布须再次校验权限、结果状态和范围；新版本替代旧指针，保留旧版本和审计 |
| 版本历史 | 版本号、计算输入摘要、配置快照、规则版本、确认/发布时间、发布状态 | 查看或比较时保持原快照；撤回要求原因且不可删除历史 |

提交写操作使用幂等键和资源预期版本；状态由专用命令推进。前端不得直接把批次状态设置成计算中、已确认或已发布。输入冻结后上传的新文件只影响后续任务。

## 6. 经营分析页面

所有分析页面采用同一查询栏：期间、授权范围、场景、当期/累计、结果版本。基地页补充结果快照粒度和特殊业务类型；FC 对比必须显示正式 FC 版本。用户选择未实现口径时，页面应禁用并解释；请求返回等待数据/口径时不显示 0 或旧值。

| 页面 | 主体内容 | 下钻/一致性规则 |
|---|---|---|
| 经营看板 | 收入、产品毛利、损益毛利、考核利润等已批准 KPI；预算达成、趋势、结构、TOP、有利/不利、亮点风险 | KPI 到损益/指标树/专题保持期间、范围、场景和版本；TOP 按绝对影响金额排序 |
| 损益表 | 行为报表项，列为 ACT、BGT、绝对 GAP、百分比 GAP、达成率；产品线/事业部提供各自要求的独立口径视图 | 展开组成项、来源、公式、更新时间和结果版本；无明细权显示授权汇总 |
| 指标树 | 考核利润为根；收入、毛利、成本、费用、减值逐层展开；显示 ACT/BGT/GAP 和贡献度 | 点击节点进入对应明细、费用或 PVM；树节点汇总与损益同版勾稽 |
| PVM | 价格、销量、结构、成本因素；基期、实际、正式分母、桥接差异 | 正式占比采用完整分析范围；页面筛选结果另标“筛选汇总”；桥接非零差异进入阻断 |
| 明细 | 标准事实、对象归属、映射、分摊链、调整、来源行 | 页面只读；修正引导至重传、配置修复或调整单；明细接口逐请求授权 |
| 非财经优率 | 期间、基地、巴长、拉线、型号、类目；目标、实际、差额、达成率、目标/实际缺侧状态 | 巴长只按映射型号授权；基地授权与巴长授权分开；比例不跨组简单平均 |
| V1.3 专题 | 基地×产品矩阵、YU、元/Wh、FC、风险一页纸、单位毛利瀑布及 P1 专题 | 未批准公式显示“待确认”；未支持场景禁用；矩阵/PDF/导出沿用页面范围与版本 |

图表需要提供与表格一致的数值和单位文本。颜色同时结合指标收益/成本属性；异常颜色不得混淆数据质量、经营异常和系统错误。查询只读取持久化结果，不隐式触发计算。

## 7. AI、权限和审计页面

- **AI 分析**：列表按期间、视角、范围、结果版本和 AI 状态筛选；详情记录六段正文、所用数据快照、提示词/模型版本、生成时间、编辑人和审阅状态。生成、编辑、确认、撤回、分发分别授权。旧分析标记所关联结果版本已替代，禁止自动挂到新版本。
- **用户/角色/范围**：展示工号、有效状态、角色、视角、数据范围、结果层级、明细、导出、上传、配置、计算、确认、发布和 AI 操作权。权限变更记录前后差异和操作者；失效用户立即不可访问。
- **审计中心**：按工号、时间、操作类型、对象、期间、追踪号查询上传、配置、异常忽略、调整、计算、确认、发布、撤回、导出、AI 和权限事件。前后值只存必要摘要，避免普通日志记录财务原文。

总部财经与运营、基地财经、BP、巴长/运营、非财经巴长和审计只读的可见页面/操作见 [接口与权限契约](03-接口任务与权限契约.md) 的角色矩阵。页面控件矩阵只改善体验，最终拒绝必须发生在服务端。

## 8. 页面验收与交付门禁

每个页面交付前至少提供：默认筛选和授权过滤、字段/单位/枚举说明、完整/空/错误/等待状态、权限正负例、筛选联动和返回行为、下钻参数、导出列、结果版本说明、至少一条财经样例和相应 UAT 编号。验收通过以服务端结果、页面展示、导出内容三者一致为准。

当前没有获批的财经黄金样本、若干页面口径和完整真实模板。因此本文件定义的是可评审的交互规格；需要真实样表或财经决策的项继续标记待确认，不能据此声称页面或正式计算已经验收。
