# 功能详细设计

## 1. 设计基线与通用交互

本文件覆盖 V1.3 第 3—5、7—8、10—18、22 章。页面中的每一条金额必须带期间、视角、数据范围、场景、结果版本和口径说明；已发布版本不可被重传或重算静默覆盖。默认查询用户有权访问的最近已发布期间。财经可预览未发布结果，但必须醒目标记。无数据、未上传、无权限、计算失败、口径未确认、无正式 FC 应分别呈现，不能以 `0` 或空白代替。

产品原型的共同筛选上下文定义为 `{period, perspective, scopeIds, resultVersion, periodMode, scenario, fcVersion?, filters}`。切换页面或下钻时保留已授权字段；服务器重新计算授权范围，不能信任 URL 中的范围。金额类显示保留底层精度、仅在页面格式化；比例/单位值由汇总分子分母重算。收益类与成本类的有利/不利方向来自指标字典。

## 2. 工作台、导入与异常（FR-WB-001、FR-IMP-001~003、FR-ERR-001）

| 页面/动作 | 输入与交互 | 服务端规则、结果及异常 |
|---|---|---|
| 月度工作台 | 期间、数据集、视角；显示必需对象完成数、阻断/警告数、最近任务、确认/发布状态与责任人 | 状态由批次完整性和任务投影生成；点击待办直达批次/异常/计算报告；没有批次提示创建，不展示假数字 |
| 模板目录 | 按数据对象下载有效模板及样例，显示模板编码/版本、字段字典和生效状态 | 隐藏模板标识或元数据必须校验；列顺序可变、已配置别名可识别；失效模板、缺列、坏文件阻断 |
| 分项上传 | 选择期间、数据集、数据对象、文件；可预检、确认提交、查看进度 | 校验通过才切换整期生效版本；原文件、Sheet/行/列、哈希、上传人和旧版本保留；重复文件需说明原因；发布后重传走重算申请 |
| 批次详情 | 对象清单、必需/条件必需/可选、有效版本、记录数、控制总额 | 缺必需项或阻断错误不得计算；“本期无数据”由财经勾选并留痕，尤其基地信用减值 |
| 数据预览 | 仅授权范围的原值、标准值、映射结果、来源定位 | 未知列保留但不计算；上传文件不可在预览页直接改写 |
| 异常工作台 | 按级别、错误码、对象、处理状态筛选；下载错误、复检、忽略警告 | 阻断项不可忽略；可忽略警告记录人/时间/原因；修复映射或重传后发起新校验；仍属必需归属的未匹配不能发布 |

批次状态机：`草稿 → 数据准备中/校验不通过 → 待计算 → 计算中 → 待确认/计算失败 → 已确认 → 已发布 → 已替代`。失败可在修复后创建新任务，旧任务保留。任何状态转换须校验操作者、前态、完整性和结果版本；同一期间同一数据集只容许一个计算中任务。AI 状态机独立为`未生成 → 生成中 → 草稿 → 已确认 → 已分发 → 已替代`，失败可重试。状态名称按业务呈现，存储枚举可用代码，但必须有统一映射表。

## 3. 配置中心（FR-CFG-001~006）

销售项目映射用出货基地＋客户简称＋客户项目改＋电芯型号精确命中产品线和事业部；先做去空格、全半角规范化，禁止模糊匹配。非财经巴长字段复用该映射，但归属匹配**仅用电芯型号**：一个型号一个有效巴长，一个巴长多个型号。库存档案支持物料多归属，数量和金额按同一比例分配，合计必须为 100%。费用字典按公司＋事业部＋三级部门＋OU 基地命中；无效/停用分类保留异常，不进入正式金额。汇率按期间＋收入计算基地＋原币唯一，国内为 1，海外缺失阻断。实验室、制造体系、总部和研发分摊展示费用池、接收对象、比例合计与完整链路；指定研发接收对象优先于比例。

基地粒度配置每基地一条有效值：`BASE_MODEL` 或 `BASE_MODEL_PROJECT`，默认后者。变更不追溯修改已发布结果；编辑页必须展示受影响期间和现有发布版本，只有显式重算才能生成新版本。配置采用增量维护、失效保留、乐观锁冲突提示。批量导入先预检，展示新增/更新/冲突/不变，再确认写入。指标字典管理编码、名称、父级、公式、单位、收益/成本属性、展示顺序和适用视角；展示属性可配置，受控公式只允许登记指标与白名单运算，复杂 PVM/分摊仍由后端版本化规则执行。公式启用前做循环依赖、单位和除零校验，并以样例试算。

## 4. 计算、调整、确认与发布（FR-CAL-001~002、FR-ADJ-001、FR-PUB-001）

财经在完整性通过后发起计算。任务页显示阶段、处理行数、异常数、耗时、追踪号及失败建议。任务开始冻结生效文件清单、配置快照、规则版本和调整单集合，写暂存结果，完成零容差勾稽后原子发布一个**候选结果版本**；任何部分失败不得暴露为有效结果。计算报告列出记录数、未匹配/排除金额、分摊守恒、损益/PVM 勾稽、调整和警告，阻断项不允许确认。财经审核确认后才可发布；发布按期间＋视角＋结果版本＋数据范围授权。新版本发布时旧版本变已替代且可追溯；撤回记录原因和通知对象。

人工调整单包含期间、视角、对象、ACT/BGT、报表项、金额和方向、原因、依据附件、录入人、状态；由总部财经或授权 BP 维护。调整作为单独计算层叠加并在明细中单列，不修改源行；跨数据集影响由财经分别指定，系统不得自动复制。已发布结果保持不变，调整生效需创建新计算版本。

## 5. 经营分析页面（FR-RPT-001、FR-PVM-001）

| 视角 | 看板/损益/下钻结构 | 口径关键点 |
|---|---|---|
| 基地 | 基地汇总、单基地、BY 月份/BY 基地损益、指标树、PVM、预算占比 | 普通业务按本次快照粒度显示型号或型号＋项目；客户项目改为零售/B品分别单列且不按型号拆分；仅宜昌 JV 销售费用，管理/研发取三级费用；闲置费用扣损益毛利，不扣产品毛利 |
| 产品线 | 看板、ACT/BGT/GAP 分页损益、PVM、型号/项目毛利及有可靠来源的专题 | 与事业部共用收入成本源；产品线不取销售/管理/财务费用；零售/B品按客户简称改2合并为 B品；正式 PVM 分母使用完整产品线范围 |
| 事业部 | 看板、ACT/BGT/GAP 分页损益、项目→型号毛利/PVM、专题 | 事业部按项目＋型号正式粒度；项目小计只汇总，不重算正式占比；取三级费用的销售/管理，不取财务费用；储能仅在产品线视角输出 |

共用看板包含 KPI、当期/累计、趋势、结构、排名、绝对及百分比 GAP、收益/成本方向、亮点/风险。损益行支持公式、来源、结果版本、更新时间与授权下钻。指标树以考核利润为根，逐级展示收入、成本、费用、减值的 ACT/BGT/GAP 和贡献。PVM 提供预算至实际收入/产品毛利桥接、因素、成本拆分、零量/新增/退出标签与未勾稽差异；筛选汇总必须与“正式占比”标识分开。所有结果页刷新只查持久化版本，不触发计算。

导出与当前已授权页面使用同一查询条件和结果版本；文件头含版本、期间、口径、导出人/时间及筛选条件。无明细权限者只可导出有权汇总。大文件异步生成，下载时再次鉴权，限时有效并记录审计。

## 6. 非财经指标（FR-RPT-002）

电芯优率由独立长表导入：期间＋基地＋拉线＋型号＋类目＋目标/实际为唯一键；重复阻断，同期重传整期替换。目标/实际按去掉类型字段的业务键配对，差额＝实际－目标，达成率＝实际÷目标，目标为零展示“—”；仅目标/仅实际是正常状态。不同基地/拉线保留明细，不简单平均比例。页面筛选期间、基地、巴长、拉线、类目，卡片展示有效/达标/未达标/未匹配型号数，明细有状态和来源行。未匹配、冲突可定位并重算；冲突阻断发布。非财经结果与财务损益/PVM/AI 正式数字隔离。总部财经全域，基地财经按基地，巴长按本人工号所映射型号在服务端过滤，导出同样执行。

## 8. AI 分析（FR-AI-001）

仅财经对已确认/已发布版本主动生成；服务端按权限组装已经勾稽的指标、趋势、PVM、费用和授权明细，异步调用公司本地网关。输出六段：经营总述、未达标事项、亮点、原因线索、风险提示、行动建议。草稿可编辑、重生成、确认、撤回、分发，重生成保留旧稿；非财经用户仅能看到已确认并分发且在本人数据范围内的版本。保存结果版本、范围、数据快照、提示词版本、模型版本、生成时间。新结果发布后旧稿标记旧版本，不能自动沿用。AI 不修改数值，不决定正式风险，不调用公网模型。

## 9. 页面原型交付清单

每个页面进入开发前，产品需补齐：字段/状态原型、默认值、空态与失败态、筛选联动、下钻路径、权限变化、导出列、验收样本。尤其基地粒度、非财经巴长、FC 状态、矩阵经营分析利润与 YU/元 Wh 等口径未确认项，原型要显示“待确认”而非演示计算值。对应决策详见 [追踪与门禁](05-追踪矩阵与待决策事项.md)。
