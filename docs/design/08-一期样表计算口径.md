## 2. 单位和损益公式

导入时统一为未舍入的人民币金额和电量，不对来源显示值作二次推测。基地实际明细 `BO/BR:BV` 为元，汇总表以 `/10000` 转成万元；`AB` 为 kWh，以 `/1000000` 转成 GWh。预算明细 `U/BX:CT` 已是万元，`W` 是 GWh。产品线/事业部实际明细 `BC/BF:BJ` 为元，预算明细 `U/BX:CT` 为万元；进入同一计算前先换算单位。源字段没有金额或电量时保留缺失状态，不把缺失等同于业务零。

对 ACT、BGT 分别计算下列行，再以 `ACT-BGT` 产生 GAP；累计先按当年 1 月至目标月求各金额和电量，再重算毛利率、利润率和单位值。

```text
制造成本 = 材料成本(含损耗) + 直接人工 + 外协 + 变动制造费用 + 固定制造费用
材料成本(不含损耗) = 材料成本(含损耗) - 材料损耗
产品毛利 = 销售收入 - 制造成本
损益毛利 = 产品毛利 - 闲置费用
基地费用 = 基地质量 + 基地 PMC + 基地运营 + 基地其他 + 物流仓储 + 质保/售后
基地项目利润 = 损益毛利 - 基地费用
基地利润 = 基地项目利润 - 研发费用 - 运营费用 - 资产减值 - 信用减值 + 其他收益
产品线利润 = 项目利润 - 研发费用 - 资产减值 - 信用减值
事业部利润 = 项目利润 - 研发费用 - 销售费用 - 管理费用 - 资产减值 - 信用减值
毛利率/利润率 = 对应未舍入金额 / 同范围销售收入；分母为零时显示空值
```

基地 `BY基地` 与 `基地汇总BY月份` 对其他收益处理不同，一期采用后者的 `+其他收益`。产品线不取销售、管理、财务费用；事业部销售和管理费用来自 `2.17三级费用明细表`，不取财务费用。研发按 `2.11`～`2.14` 汇总。事业部项目利润与费用项目若样表源数据缺失，显示“缺数据”并保留来源差额，不借用其他视角的结果。

结果键 `PRODUCT_GROSS_PROFIT` 表示未扣闲置的产品毛利，`PNL_GROSS_PROFIT` 表示扣闲置后的损益毛利，`PROJECT_PROFIT` 表示再扣基地/当前范围费用后的项目利润。为兼容现有接口，旧键 `GROSS_PROFIT` 暂等同产品毛利；PVM 始终使用产品毛利。

## 3. 一期 PVM

PVM 按样表的电芯型号及当前分析范围汇总 ACT、BGT。`Qa/Qb` 为电量，`Pa/Pb` 为金额除以对应电量，`Ca/Cb` 为制造成本除以对应电量，`Mb=Pb-Cb`，`预算量占比=Qb/ΣQb`，`预算平均单位毛利=Σ预算产品毛利/ΣQb`。使用完整当前分析范围计算这些公共分母，页面筛选只汇总既有因素，不重新计算占比。

```text
收入价差 = (Pa-Pb)×Qa
收入量差 = (ΣQa×预算量占比-Qb)×Pb
收入结构差 = (Qa-ΣQa×预算量占比)×Pb
毛利价差 = (Pa-Pb)×Qa
毛利量差 = (Qa-Qb)×预算平均单位毛利
毛利成本差 = -(Ca-Cb)×Qa
毛利结构差 = (Qa-ΣQa×预算量占比)×(Mb-预算平均单位毛利)
```

`Qa=0` 或 `Qb=0` 时，按照样表 `2.3`/`2.4` 的 `IF(K*AE=0,...)` 分支：价、量、成本为零，收入差和产品毛利差全归结构因素，单位值显示空值。材料成本含材料损耗；若展示“材料差”和“损耗差”，材料差先扣损耗，二者才可相加。人工、外协、变动和固定制造费用按同样的单位成本差分列。

每次计算记录 `收入桥差额` 和 `产品毛利桥差额`。样表自身 8 月产品毛利桥约差 4.51 万元、累计约差 1.12 万元；一期保留并展示差额，不将它分摊进其他因素，也不因这类样表原生 PVM 差额阻断损益发布。收入、成本组成、来源总额、版本和权限检查仍需通过。

## 4. 一期范围与版本

- 一期计算 ACT、BGT、GAP、当期和累计；正式 FC 治理、YU、线体元/Wh、库龄风险阈值和研发提单流程未在两份样表给出完整算法，不作为一期上线门禁，也不输出自造的正式值。
- 基地、产品线、事业部的损益先按现有导入范围出数；可下钻维度保留基地、事业部、产品线、客户项目、客户简称和型号。PVM 一期按样表的型号汇总，客户项目多维 PVM 后续版本扩展。
- 沿用现有 `calc.pnl_result`/结果版本机制；PVM 一期随损益版本计算并返回因素与差额。计算中保留原始精度，存储沿用现有 `NUMERIC(24,8)`，界面只在展示时格式化。无单独行级版本号，行继承所属结果版本。
- 本文件只确定计算和一期范围。生产身份、行级授权及导出权限仍按安全接口契约实施，不从样表推断。
