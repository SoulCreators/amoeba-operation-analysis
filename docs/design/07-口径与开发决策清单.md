# 口径与开发决策清单

> **一期口径决定（2026-10-23）：**需求负责人已明确直接采用两份财务样表，优先上线基础 ACT/BGT/累计损益及样表 PVM。计算公式、零量分支、材料损耗、范围和已知差额按 [08-一期样表计算口径](08-一期样表计算口径.md) 执行。下列清单保留为原始问题记录；其中与一期样表口径冲突的“待财经签字”“硬阻断”和“零差异”要求，不再阻断一期公式实施。安全接线及无法由样表提供的功能仍按各自交付条件处理。

## 一、FR-RPT-001（累计 + 正式金额 + 结果版本）

| 编号 | 类型 | 需要明确的内容 | 阻断程度 |
|---|---|---|---|
| RPT-1 | 表结构 | `metric_result` / `pvm_result` 正式结果表的物理结构：未舍入金额 `NUMERIC(p,s)` 精度、分子/分母是否同表、`trace_id` 取值规则、`result_status` 枚举、三视角「正式粒度」用哪些列表达 | 🔴 硬阻断 |
| RPT-2 | 口径 | 累计 = 当年 1 月至指定月各当期合计的**适用范围**：所有视角×所有场景都出累计？比率/单价的重算分母口径 | 🔴 硬阻断 |
| RPT-3 | 口径 | **舍入边界**：未舍入值在哪个环节产生、展示舍入在哪个环节、已发布 vs 草稿金额是否分开存 | 🔴 硬阻断 |
| RPT-4 | 范围 | PVM 是否纳入本次正式结果落库（当前纯内存计算、零持久化） | 🟡 定范围 |
| RPT-5 | 范围 | 行级结果是否带 `versionNo`（需改领域模型 + 服务 + 测试 + 前端），还是顶层 `versionNo` 已够用 | 🟡 定工作量 |

## 二、FR-PVM-001（正式客户/项目粒度 + 结构因素）

| 编号 | 类型 | 需要明确的内容 |
|---|---|---|
| PVM-1 | 口径 | 零量 / 新增 / 退出业务的**归集规则**（不得除零），需财经批准零量规则 |
| PVM-2 | 口径 | 完整**结构因素**清单：价格 / 销量 / 成本 / 结构四因素是否都落库；材料损耗如何避免与材料成本重复计入 |
| PVM-3 | 口径 | 正式粒度是否按设计冻结：基地=配置粒度；基地零售/B品=基地+特殊类型；产品线=产品线+客户项目+客户简称改2+型号；事业部=事业部+客户项目+型号 |
