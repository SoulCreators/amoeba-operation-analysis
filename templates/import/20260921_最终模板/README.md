# 经营分析平台最终导入模板

本目录共19份Excel模板，每份固定包含 `数据录入`、`字段说明`、`示例数据` 三张表。

## 导入原则

1. 收入成本、期间费用、闲置费用、减值结果、其他收益及非财经指标按期间整期覆盖；年度预算按年度导入。
2. 映射、分摊、汇率、基地粒度、指标库、用户权限和非财经指标巴长映射属于基础配置，按键增量维护；`是否有效=否`时不参与计算或授权。
3. 基地与产品线/事业部业务数据分开导入；经营总览使用统一指标口径，三套视角的明细计算规则分别执行。
4. 国内基地汇率填1，海外匈牙利、泰国按财经提供的期间汇率填写。
5. 基地收入成本明细中的 `不计算=是` 不纳入基地统计及PVM；产品线/事业部将 `客户项目-改=零售/B品` 统一归为 `B品`。
6. 销售成本直接取正式销售成本字段；成本构成字段用于分析和勾稽，不反向覆盖正式销售成本。
7. 非财经指标采用长表导入：一行对应一个期间、基地、拉线、电芯型号、类目和目标/实际值。系统复用 `21-销售项目映射.xlsx` 中的 `电芯型号—巴长`字段，仅按电芯型号读取巴长映射，同一巴长可关联多个电芯型号。
8. 非财经指标页面按目标值、实际值、差额（实际-目标）和达成率展示，并按巴长权限隔离数据。
9. 正式上传时不要修改字段名称、顺序和数据类型，不要新增标题行、合并单元格或小计行。
